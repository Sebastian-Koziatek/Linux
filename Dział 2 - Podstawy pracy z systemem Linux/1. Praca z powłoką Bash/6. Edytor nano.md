# Edytor nano

> **W tej lekcji:** nauczysz się edytować pliki w nano – edytorze bez trybów, z podpowiedziami
> na ekranie – i dowiesz się, kiedy sięgnąć po nano, a kiedy po vima.

Nano to edytor, który „po prostu działa”: otwierasz plik, piszesz, zapisujesz. Nie ma trybów,
nie ma zagadki „jak wyjść” – najważniejsze skróty są cały czas wypisane na dole ekranu. Dla
codziennych drobnych poprawek w plikach konfiguracyjnych to najszybsza droga, szczególnie na
początku przygody z Linuksem.

Haczyk jest jeden: nano nie wszędzie jest zainstalowane (w minimalnej instalacji RHEL go nie ma –
doinstalujesz przez `sudo dnf install nano`), a vi jest zawsze. Dlatego nano traktuj jako wygodę,
a podstawy vima z poprzedniej lekcji – jako obowiązek.

## Jak to działa

Nano zajmuje cały ekran terminala:

- u góry – nazwa pliku i informacja o zmianach (`Modified`),
- w środku – treść, piszesz od razu, bez żadnych trybów,
- na dole – **pasek pomocy** z najważniejszymi skrótami.

W pasku pomocy `^` oznacza `Ctrl` (np. `^X` = `Ctrl+X`), a `M-` oznacza `Alt` (np. `M-U` =
`Alt+U`). Wystarczy czytać stopkę, żeby obsłużyć edytor – to cała filozofia nano.

## W praktyce

### Edycja krok po kroku

```bash
# otwórz (lub utwórz) plik
nano notatki.txt
```

1. Pisz od razu – znaki trafiają do pliku, strzałki przesuwają kursor.
2. Zapis: `Ctrl+O` (ang. *write Out*), nano pyta o nazwę pliku – zatwierdź `Enter`.
3. Wyjście: `Ctrl+X`. Jeśli są niezapisane zmiany, nano zapyta: `Y` zapisuje (potem `Enter`
   potwierdza nazwę), `N` porzuca zmiany, `Ctrl+C` wraca do edycji.

W praktyce najszybciej: edytujesz, `Ctrl+X`, `Y`, `Enter`.

### Skróty, które musisz znać

| Skrót | Co robi |
|---|---|
| `Ctrl+O` | zapisz plik |
| `Ctrl+X` | wyjdź (zapyta o zapis, jeśli trzeba) |
| `Ctrl+W` | szukaj (ang. *Where is*); `Alt+W` – następne wystąpienie |
| `Ctrl+K` | wytnij cały bieżący wiersz |
| `Ctrl+U` | wklej wycięty tekst |
| `Ctrl+G` | pełna pomoc (wyjście z pomocy: `Ctrl+X`) |

I kilka wygodnych:

| Skrót | Co robi |
|---|---|
| `Ctrl+\` | szukaj i zamień (pyta o każdą zamianę) |
| `Ctrl+_` | skocz do podanego numeru wiersza |
| `Ctrl+C` | pokaż pozycję kursora (wiersz, kolumna) |
| `Ctrl+A` / `Ctrl+E` | początek / koniec wiersza |
| `Alt+U` | cofnij; `Alt+E` – przywróć |

Kilka naciśnięć `Ctrl+K` pod rząd wycina kolejne wiersze do wspólnego schowka – `Ctrl+U` wklei
je wszystkie naraz.

### Przydatne opcje przy uruchamianiu

```bash
# -l: pokazuj numery wierszy (przy błędach typu "error in line 42" bezcenne)
nano -l /etc/hosts
```

```bash
# otwórz plik od razu na wierszu 42
nano +42 skrypt.sh
```

> **Pliki systemowe** edytujesz z `sudo`: `sudo nano /etc/hosts`. Bez tego nano otworzy plik,
> ale przy zapisie zgłosi *Permission denied*.

### Kiedy nano, kiedy vim

| Sytuacja | Wybór |
|---|---|
| szybka poprawka, własna maszyna, nano jest zainstalowane | nano |
| serwer, na którym jest tylko podstawowa instalacja | vim (vi jest zawsze) |
| duże zmiany: masowa zamiana, praca na setkach wierszy | vim – szybszy przy wprawie |
| narzędzie samo otwiera edytor (`visudo`, `crontab -e`) | ten, który wyskoczy – domyślnie często vim; można to zmienić zmienną `EDITOR` |

Chcesz, żeby narzędzia systemowe otwierały nano zamiast vima? Dodaj do `~/.bashrc`:
`export EDITOR=nano` (jak działa `export` – lekcja [Zmienne i aliasy](9.%20Zmienne%20i%20aliasy.md)).

## Najczęstsze błędy i pułapki

1. **Szukanie „trybu wstawiania”.** W nano go nie ma – po prostu pisz. Jeśli litery nie
   pojawiają się tam, gdzie chcesz, sprawdź położenie kursora.
2. **`Ctrl+S` z przyzwyczajenia.** W nowszych wersjach nano zapisuje plik, ale w niektórych
   terminalach najpierw „zamraża” ekran – jeśli wszystko stanęło, naciśnij `Ctrl+Q`.
   Pewny zapis to `Ctrl+O`.
3. **Zmiana nazwy pliku przy zapisie przez przypadek.** Po `Ctrl+O` nano pokazuje nazwę do
   edycji – jeśli coś dopiszesz, zapiszesz pod inną nazwą. Zwykle wystarczy `Enter`.
4. **Automatyczne zawijanie długich wierszy.** Przy wklejaniu długich linii konfiguracji nano
   potrafi je rozbić (zależnie od ustawień). Jeśli edytujesz plik wrażliwy na podział wierszy,
   uruchom `nano -w plik`.
5. **Brak nano na serwerze.** *command not found* – nie instaluj odruchowo na cudzej maszynie;
   po prostu użyj vi. Do tego służył zestaw ratunkowy z poprzedniej lekcji.

## Podsumowanie

- Nano edytuje bez trybów; skróty masz zawsze w stopce: `^` = `Ctrl`, `M-` = `Alt`.
- Cykl pracy: `nano plik` → edycja → `Ctrl+X`, `Y`, `Enter`.
- `Ctrl+W` szuka, `Ctrl+K`/`Ctrl+U` wycina i wkleja wiersze, `Ctrl+G` to pomoc.
- `nano -l` pokazuje numery wierszy; `sudo nano` do plików systemowych.
- Nano to wygoda, vi to pewność – znaj oba.

| Skrót / polecenie | Co robi |
|---|---|
| `nano plik` | otwórz plik |
| `nano -l plik` | z numerami wierszy |
| `Ctrl+O`, `Enter` | zapisz |
| `Ctrl+X` | wyjdź |
| `Ctrl+W` | szukaj |
| `Ctrl+K` / `Ctrl+U` | wytnij / wklej wiersz |
| `Ctrl+\` | szukaj i zamień |
| `Ctrl+G` | pomoc |
