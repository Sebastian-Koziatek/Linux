Piekło zależności

dwa programy, jedna biblioteka, dwie różne wersje

Program A

zainstalowany, działa

wymaga: biblioteka ≥ 2.0

Program B

chcesz go zainstalować

wymaga: biblioteka < 2.0

biblioteka (jeden pakiet w systemie)

zainstalowana wersja: 2.1 – nie da się mieć jednocześnie 2.1 i 1.9 w tym samym miejscu

tak to wygląda w praktyce
[admin@serwer ~]$ sudo dnf install program-b
Błąd:
 Problem: cannot install the best candidate for the job
  - nothing provides biblioteka < 2.0 needed by program-b-3.4-1.el9.x86_64
Menedżer pakietów nie „psuje” niczego – odmawia, bo nie ma dobrego rozwiązania. Obejście siłą (rpm --nodeps, --force) zostawi system w stanie, w którym program A przestanie działać.
