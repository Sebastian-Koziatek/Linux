Który rodzaj instalacji?

„podstawowe środowiska” instalatora Anaconda

Minimal Install serwer

Tylko to, co konieczne: powłoka, sieć, SSH, dnf. Ok. 1,5 GB na dysku. Wszystko inne doinstalujesz sam. Tak stawia się serwery.

Server

Minimal + typowe narzędzia administratora (np. Cockpit, narzędzia diagnostyczne). Bez pulpitu. Dobry start dla początkującego administratora.

Server with GUI

Server + pulpit GNOME. Kilka GB więcej na dysku, więcej RAM. Gdy chcesz klikać podczas nauki albo serwer stoi pod biurkiem z monitorem.

Workstation

Pulpit GNOME + programy biurowe, przeglądarka, multimedia. Komputer do codziennej pracy, nie serwer.

Na szkoleniu używamy Minimal Install lub Server. Pulpit zawsze da się dodać później: dnf group install "Server with GUI".
