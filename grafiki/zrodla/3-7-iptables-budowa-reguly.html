Budowa reguły iptables

blokada ruchu z jednego adresu
blokujemy adres 192.168.10.240
[admin@serwer ~]$ sudo iptables -A INPUT -s 192.168.10.240 -j DROP

-A dodanie reguły

Dopisuje ją na koniec łańcucha. -I wstawia na początek, -D usuwa.

INPUT łańcuch

Rodzaj ruchu: INPUT – pakiety przychodzące do serwera, OUTPUT – wychodzące, FORWARD – przekazywane dalej.

-s 192.168.10.240 dopasowanie

Których pakietów dotyczy: adres lub sieć źródłowa. Inne dopasowania to m.in. -p tcp i --dport 25.

-j DROP cel

Co zrobić z pasującym pakietem: DROP – wyrzuć po cichu, REJECT – odrzuć z komunikatem, ACCEPT – przepuść.

Każda reguła odpowiada na trzy pytania: gdzie ją wpisać (łańcuch), czego dotyczy (dopasowania) i co z tym zrobić (cel).
