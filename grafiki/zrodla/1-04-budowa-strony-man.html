LS(1)          User Commands          LS(1)

NAME
       ls - list directory contents

SYNOPSIS
       ls [OPTION]... [FILE]...

DESCRIPTION
       List information about the FILEs
       (the current directory by default).

       -a, --all
              do not ignore entries starting with .

       -l     use a long listing format
       …
EXAMPLES
       …
SEE ALSO
       Full documentation
       <https://www.gnu.org/software/coreutils/ls>

 Manual page ls(1) line 1 (press h for help or q to quit)

Nagłówek LS(1)

Nazwa i numer sekcji: 1 = polecenia użytkownika.

NAME

Jedno zdanie, co to robi. To przeszukuje apropos.

SYNOPSIS – jak wywołać

[ ] = można pominąć, … = można powtórzyć, | = albo-albo, pogrubione = wpisz dosłownie.

DESCRIPTION / OPTIONS

Pełny opis i lista opcji. Szukaj opcji przez /-l.

EXAMPLES, SEE ALSO

Gotowe przykłady i powiązane strony – często najcenniejsza część.

Pasek na dole

Jesteś w programie less: spacja = dalej, / = szukaj, q = wyjdź.
