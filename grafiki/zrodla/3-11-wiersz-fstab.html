Jeden wiersz pliku /etc/fstab

sześć pól oddzielonych spacjami lub tabulatorami
/etc/fstab – wpis dla dysku z danymi
# co           gdzie       typ   opcje            dump  pass
UUID=3f1c…9a  /mnt/dane   xfs   defaults,nofail  0     0
   ①             ②         ③          ④           ⑤     ⑥

Co montować

UUID=… – trwały identyfikator systemu plików (z blkid). Może być też LABEL=dane albo /dev/sdb1, ale nazwa sdX potrafi się zmienić.

Gdzie

Punkt montowania – istniejący, najlepiej pusty katalog.

Typ

xfs, ext4, vfat, iso9660, nfs, swap… albo auto.

Opcje

defaults wystarcza. Przydatne dodatki: nofail (brak dysku nie zatrzyma startu), noatime, ro.

Dump

Historyczny znacznik dla programu dump. Dziś zawsze 0.

Pass

Kolejność fsck przy starcie: 1 dla / (ext4), 2 dla pozostałych ext, 0 = nie sprawdzaj (XFS, nośniki wymienne).

Literówka w tym pliku potrafi zatrzymać start systemu. Po każdej zmianie: sudo mount -a i findmnt --verify, zanim zrobisz restart.
