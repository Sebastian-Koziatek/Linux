# Moduł 23. Certyfikat SSL w Apache

Ten moduł wykracza poza program szkolenia – jest dla chętnych. Każda poważna strona działa dziś
po HTTPS. Zrozumiesz, co właściwie szyfruje HTTPS i czym jest certyfikat oraz urząd certyfikacji,
a potem przejdziesz całą drogę administratora: uruchomisz serwer Apache z certyfikatem
samopodpisanym, nauczysz się podmieniać certyfikat na kupiony od CA i poznasz darmową
automatyzację z Let's Encrypt.
