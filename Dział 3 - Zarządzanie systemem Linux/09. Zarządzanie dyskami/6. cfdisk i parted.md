# cfdisk i parted

> **W tej lekcji:** poznasz dwie alternatywy dla `fdisk`: wygodny, okienkowy `cfdisk` oraz `parted` – narzędzie do dysków powyżej 2 TB i do skryptów.

## Po co mi to?

`fdisk` wystarcza do codziennej pracy, ale nie zawsze jest najwygodniejszy. Gdy wolisz widzieć cały układ dysku i poruszać się strzałkami – jest `cfdisk`. Gdy partycjonujesz dyski w skrypcie instalacyjnym albo pracujesz z macierzą 20 TB – sięgniesz po `parted`. Wszystkie trzy robią to samo (zapisują tablicę partycji), różnią się obsługą i możliwościami.

## Jak to działa

### cfdisk – fdisk z menu

`cfdisk` (z tego samego pakietu `util-linux` co `fdisk`) rysuje w terminalu pseudograficzny interfejs: u góry lista partycji, na dole menu. Poruszasz się strzałkami: góra/dół wybiera partycję, lewo/prawo – pozycję menu, Enter zatwierdza. Jak w `fdisk`, **nic nie trafia na dysk przed wybraniem `Write`**.

```bash
sudo cfdisk /dev/sdb
```

```text
                                 Disk: /dev/sdb
               Size: 10 GiB, 10737418240 bytes, 20971520 sectors
                     Label: gpt, identifier: 1D6E0F6A-…

    Device              Start          End      Sectors     Size Type
>>  /dev/sdb1            2048     10487807     10485760       5G Linux filesystem
    Free space       10487808     20971486     10483679       5G

 ┌────────────────────────────────────────────────────────────────────┐
 │  [ Delete ]  [ Resize ]  [ Quit ]  [ Type ]  [ Help ]  [ Write ]   │
 │  [ Dump ]                                                          │
 └────────────────────────────────────────────────────────────────────┘
```

Pozycje menu odpowiadają literom `fdisk`: `New` = `n`, `Delete` = `d`, `Type` = `t`, `Write` = `w`, `Quit` = `q`. Na pustym dysku `cfdisk` najpierw pyta o typ etykiety (wybierz `gpt`). Przed zapisem każe wpisać słowo `yes` – ostatni bezpiecznik.

Dla początkującego to najprzyjemniejsza droga: cały czas widzisz skutki swoich decyzji, a wolne miejsce jest pokazane wprost jako `Free space`.

### parted – dyski bez limitu i tryb skryptowy

`parted` (pakiet `parted`, na RHEL instalowany domyślnie) od zawsze obsługuje GPT i dowolnie wielkie dyski – dlatego przez lata był narzędziem „do dysków powyżej 2 TB", gdy stare wersje fdiska znały tylko MBR. Ma dwie cechy, których nie mają `fdisk`/`cfdisk`:

- **tryb skryptowy** `-s`: całe partycjonowanie jednym poleceniem, bez dialogu – idealne do automatyzacji;
- rozmiary podajesz w jednostkach (`MiB`, `GiB`, `%`), a `parted` sam wyrówna partycje.

Jest też cecha, przez którą trzeba uważać:

> **Uwaga:** `parted` **zapisuje zmiany natychmiast**, po każdym poleceniu. Nie ma bufora w pamięci, nie ma `w` ani `q` bez zapisu. `mkpart` wykonany = partycja istnieje.

## W praktyce

### parted interaktywnie

```bash
sudo parted /dev/sdc
```

```text
GNU Parted 3.5
Using /dev/sdc
Welcome to GNU Parted! Type 'help' to view a list of commands.
(parted) mklabel gpt
(parted) mkpart dane xfs 1MiB 5GiB
(parted) mkpart lvm 5GiB 100%
(parted) set 2 lvm on
(parted) print
Model: ATA QEMU HARDDISK (scsi)
Disk /dev/sdc: 10,7GB
Sector size (logical/physical): 512B/512B
Partition Table: gpt

Number  Start   End     Size    File system  Name  Flags
 1      1049kB  5000MB  4999MB  xfs          dane
 2      5000MB  10,7GB  5738MB               lvm   lvm
(parted) quit
Information: You may need to update /etc/fstab.
```

Co tu się stało:

- `mklabel gpt` – nowa tablica GPT (odpowiednik `g` w fdisk). Na dysku z partycjami `parted` zapyta o potwierdzenie, bo kasuje ich spis – **od razu, naprawdę**.
- `mkpart dane xfs 1MiB 5GiB` – partycja o nazwie `dane`, od 1 MiB do 5 GiB. Podany system plików (`xfs`) to tylko podpowiedź typu – `parted` **nie formatuje**; `mkfs` i tak uruchamiasz osobno.
- `set 2 lvm on` – flaga `lvm` na drugiej partycji (odpowiednik typu Linux LVM).
- Początek od `1MiB`, nie od zera – pierwsze sektory zajmuje tablica partycji, a wyrównanie do 1 MiB zapewnia pełną wydajność dysków SSD i macierzy. Gdy podasz złe granice, `parted` ostrzeże: *The resulting partition is not properly aligned for best performance*.

Inne przydatne polecenia trybu interaktywnego: `print free` (pokaż też wolne miejsce), `rm 2` (usuń partycję 2 – natychmiast!), `unit GiB` (zmień jednostkę wyświetlania), `help mkpart` (pomoc do polecenia).

### parted w skrypcie

```bash
# całe partycjonowanie dysku jednym poleceniem – tak robią to skrypty instalacyjne
sudo parted -s /dev/sdc -- mklabel gpt mkpart dane xfs 1MiB 5GiB mkpart lvm 5GiB 100% set 2 lvm on
```

Opcja `-s` (ang. *script*) wyłącza pytania – `parted` przyjmuje wszystkie decyzje bez potwierdzeń. Podwójny myślnik `--` pozwala użyć `100%` bez pomylenia go z opcją. To polecenie wykonuje się w sekundę i od razu zmienia dysk, więc w skryptach zawsze poprzedza się je sprawdzeniem, czy na pewno pracujemy na właściwym urządzeniu.

```bash
# kontrola – niezależnie od użytego narzędzia
lsblk /dev/sdc
```

```text
NAME   MAJ:MIN RM SIZE RO TYPE MOUNTPOINTS
sdc      8:32   0  10G  0 disk
├─sdc1   8:33   0  4,7G  0 part
└─sdc2   8:34   0  5,3G  0 part
```

## Najczęstsze błędy i pułapki

- **Traktowanie `parted` jak `fdisk`.** Największa pułapka tej lekcji: w `parted` nie ma „wyjścia bez zapisu”. `mklabel` na złym dysku właśnie skasował spis partycji. Zanim naciśniesz Enter – przeczytaj polecenie jeszcze raz.
- **Oczekiwanie, że `mkpart … xfs …` sformatuje partycję.** Nie – to tylko etykieta typu. System plików tworzysz poleceniem `mkfs.xfs` (moduł 11).
- **`mkpart` od sektora 0.** Zostaw 1 MiB na początku; inaczej partycja nachodzi na tablicę albo jest źle wyrównana.
- **Mylenie nazw partycji GPT z etykietami systemu plików.** `mkpart dane …` nadaje nazwę w tablicy GPT; etykieta, którą widzi `lsblk -f`, powstaje przy formatowaniu (`mkfs.xfs -L DANE`).

## Podsumowanie

- `cfdisk` = `fdisk` z menu i strzałkami; zmiany zapisuje dopiero `Write` + `yes`. Najlepszy na początek.
- `parted` = narzędzie do dużych dysków i skryptów (`-s`); **każde polecenie zapisuje się natychmiast**.
- Żadne z tych narzędzi nie tworzy systemu plików – partycjonowanie i formatowanie to osobne kroki.
- Niezależnie od narzędzia efekt sprawdzasz tak samo: `lsblk`, `sudo parted /dev/sdX print`.

| Polecenie | Do czego |
|---|---|
| `sudo cfdisk /dev/sdb` | partycjonowanie w interfejsie okienkowym |
| `sudo parted /dev/sdc print free` | układ partycji + wolne miejsce |
| `mklabel gpt` | nowa tablica GPT (natychmiast!) |
| `mkpart nazwa xfs 1MiB 5GiB` | nowa partycja od–do |
| `rm 2` / `set 2 lvm on` | usuń partycję / ustaw flagę |
| `sudo parted -s /dev/sdc -- …` | tryb skryptowy, bez pytań |
